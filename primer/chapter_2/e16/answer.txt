Which, if any, of the following assignments are invalid? If they are
valid, explain what they do.

int i = 0, &r1 = i;
double d = 0, &r2 = d;

(a) r2 = 3.14159;
(b) r2 = r1;
(c) i = r2;
(d) r1 = d;

answer:
(a) This is valid, we reasigning the value of an object that is referenced by r2, that is the value of d to 3.14159.
(b) This is valid, its assign the value of d with the value of i through their references that is r2 and r1.
(c) this is valid, the value of i is now the value of object which r2 is referencing, which is the value of d, that is 0.
(d) This is valid, its reasign the value of i through its refernce that is r1 with the value of d.
