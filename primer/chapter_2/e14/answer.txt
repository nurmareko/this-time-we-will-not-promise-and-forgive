Exercise 2.14: Is the following program legal? If so, what values are printed?
int i = 100, sum = 0;
for (int i = 0; i != 10; ++i)
sum += i;
std::cout << i << " " << sum << std::endl;

answer:
  Indeed legal, it will print: 100 45
  the 100 come from the i value define about the for loop. The value of sum is incremented by the value of i define inside the for loop.
